# EdgeLog

**Find Your Edge.**

EdgeLog is a professional trading journal focused on deliberate manual entry and edge discovery.

## Product

EdgeLog helps traders:
- Document what actually happened
- Evaluate execution quality
- Identify behavioral patterns
- Discover statistical edge

## Tech Stack

- **Frontend:** Vue 3, Pinia, Vite
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy 2.x
- **Auth:** JWT with HttpOnly refresh cookies
