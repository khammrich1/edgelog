# P2 — Dashboard / First Impression

See issue #undefined.

## North Star

Within seconds of login, EdgeLog should answer:

**How am I doing? → What happened recently? → What should I do next?**

The Dashboard is the trader's daily command center, not a collection of decorative metrics.

## Product constraints

Use canonical EdgeLog data. Never invent P&L, R, win rate or other performance values. Use the P1 visual system and preserve its dense trading-workstation character.

Prioritize today's journal/trading state, a truthful recent-performance snapshot, recent activity, and one obvious next action back into the TRADE → REFLECT → IMPROVE loop.

Setup is first-class context for new trades, but full Trade Ranker / Edge Discovery remains outside P2.
